# Admin 后台与中继流量历史实施计划

> 本文记录后台与流量历史的初版实施计划。其中按 UTC 固定结算的方案已由站点结算时区取代。当前默认使用 `Asia/Shanghai`，实际行为与部署步骤见 [README](../../../README.md)。

**目标**：提供需登录的单管理员后台，支持中继密钥和每日额度配置、运行概览、历史流量查询，以及单机 Docker Compose 部署。

**架构**：沿用 Go 服务、TypeScript/Vite 和现有 TURN 计量。Admin 作为同源独立页面，配置与流量账本持久化到同一个数据卷，继续采用单实例文件锁。

## 任务一：统一持久化与账本迁移

- [ ] 在 `quota.go` 扩展版本化账本。读取旧文件的日期和两个额度池用量，迁移时保留已扣额度。继续在放行转发前持久化预留块，并复用现有临时文件、原子替换和目录同步机制。
- [ ] 按 UTC 日归档公共与保留额度用量。归档时扣除进程仍能确认的未使用预留；进程异常退出可能使每池不足 256 KiB 的预留被计入消耗。跨日与第一笔新日扣费在同一持久化提交中完成；启动和查询能处理空闲跨日。
- [ ] 默认保留 90 个 UTC 日，管理员可切换最近 7、30 或 90 天，默认 30 天。迁移前缺少记录的日期标为无数据；受覆盖且持续可计量的日期零流量显示为 0。账本保留必要的覆盖信息，服务离线或中继禁用时避免把未知日期填成零。
- [ ] 验证旧账本迁移、同日重启、UTC 跨日、长时间空闲、保留期裁剪和写入失败。中继应在账本无法安全更新时停止放行。

## 任务二：管理员登录与会话

- [ ] 新增 Go Admin 路由及独立 Vite 入口。使用 `/admin/` 页面和 `/api/admin/` 接口。Docker 配置提供账号和密码，支持以文件方式注入密码。两项均缺失时关闭后台，缺一项时报启动配置错误。
- [ ] 登录成功后生成随机服务端会话，使用 HttpOnly、生产 Secure 和 SameSite=Strict Cookie，固定 8 小时有效期。退出时撤销会话，重启后重新登录。限制登录尝试，对写请求验证同源，并为后台 API 响应禁用缓存。
- [ ] 验证未登录 API、错误密码、限流、过期与退出、跨站写请求，以及关闭 Admin 时公开传输流程可用。

## 任务三：中继配置热更新

- [ ] 持久化管理员覆盖配置。已有环境变量作为初始默认值；后台保存后，已设置字段优先。密钥字段区分保持、替换、清空三种操作。服务端仅保存验证所需的摘要和换钥所需的版本，接口只返回是否已设置。
- [ ] 保存时验证两项额度为有效的非负整数字节数，检查合计不会溢出。配置写入成功后再发布新设置。降低额度后以已计量的消耗为准，余额可降至零，额度生效和 TURN 扣费受同一并发控制。
- [ ] 轮换或清空密钥后，旧密钥无法取得新授权。正在运行的已授权 TURN 凭据保留到现有过期时间；断线、新一轮连接或续发凭据时按新版本验证。替换文件前写入失败时继续使用上一次确认生效的设置。替换后若目录同步失败，报告持久化状态不确定，并暂停新中继授权及流量转发，直至恢复可信配置。
- [ ] 验证配置重启后仍生效、降低额度不重置消耗、额度为零、并发扣量与编辑、密钥轮换及清空。

## 任务四：仪表盘和趋势

- [ ] 在 Go 管理接口提供今日两个额度池的已用、上限和剩余，返回 UTC 日期的历史序列。今天的图表点和概览复用同一快照。历史图按额度消耗显示，包含协议开销和重传。
- [ ] 复用信令的房间、连接状态及失败原因，展示活跃配对、双方已就绪的直连和中继配对，以及进程启动以来的失败计数。统计按配对汇总，历史仅持久化中继用量。直连流量不由后台估算。
- [ ] Admin 页面提供登录、概览、趋势、设置和退出。趋势支持日期与流量读数、缺失数据状态及移动端窄屏。接口和页面均不返回密码、中继密钥、配对码、文件名和传输内容。
- [ ] 验证两类额度的图表口径、周期切换、空状态、超限显示，以及公开页面的配对和传输回归。

## 任务五：Docker Compose 与联调

- [ ] 增加多阶段 Dockerfile、Compose 示例和部署说明。镜像内构建 Vite 和 Go，运行时使用非 root 用户。容器对外发布 HTTPS 和 TURN UDP，按需启用 TURN TLS。域名、公告 IPv4、证书路径及管理员账号从部署配置提供。
- [ ] Compose 挂载密码文件、只读证书及可写持久卷。数据卷保存后台设置和流量历史，提供备份、恢复、替换管理员密码和切换 TURN 开关的说明。
- [ ] 运行 `go test -race ./...`、前端类型检查、测试和生产构建。构建镜像并验证健康检查、管理员登录、改密钥、真实 TURN 产生用量，以及重建容器后设置与用量可读。公网验收结合现有 Chrome/Edge 双设备流程，验证直连、中继及额度耗尽后的行为。

## 待确认的实施默认值

- 历史保留先按 90 天设计，默认展示最近 30 天。
- 密钥轮换对新授权立即生效，已有授权保留到当前凭据过期。
- 首版交付 Docker Compose 部署文件，实际部署使用运营方提供的域名、证书与公网地址。
